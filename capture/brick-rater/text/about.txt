Quality

Builder quality, not value

06

Quality, scored separately

How builders rate a set says nothing about price, so it gets its own 0–100 score and never changes the value score.

Start with the Brickset rating (sets need 5+ ratings).
Steady it with 30 extra ratings at the average for similar sets, so a few early ratings can’t dominate.
Rank it against sets of the same kind and size from every theme: display sets with display sets, play sets with play sets.
